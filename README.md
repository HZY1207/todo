# 待办清单

简约护眼待办事项应用，纯静态，无需构建工具。

## 功能

- 清单视图：添加 / 完成 / 编辑（双击文本）/ 删除待办，筛选（全部 / 进行中 / 已完成）
- 月历视图：每天格子上显示待办圆点，点击日期查看并管理当日待办
- 三套护眼主题：绿白 / 黑白 / 蓝白（设置中切换，自动记忆）
- 数据保存在浏览器 localStorage（各设备独立）
- 导出导入 JSON，实现手机 ↔ 电脑数据互通
- PWA：手机浏览器可"添加到主屏幕"，安装后离线可用

## 本地运行

```bash
python -m http.server 8000
# 或任意静态服务器，浏览器打开 http://localhost:8000
```

直接双击 `index.html` 也能用，但 PWA 的 Service Worker 需要 HTTPS 或 localhost。

## 部署到 GitHub Pages（手机与电脑共用）

1. 创建 GitHub 仓库，将本目录推送上去
2. 仓库 Settings → Pages → Source 选择 `main` 分支 `/` 根目录，保存
3. 等待 1~2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

之后手机和电脑都打开同一链接使用。手机"添加到主屏幕"后即是独立 App 图标。

## 数据互通

1. 手机上 设置 → 导出数据 → 得到 `todo-backup-日期.json` 文件
2. 通过微信 / 网盘 / 邮件把该文件发给电脑
3. 电脑上打开同一网页 → 设置 → 导入数据 → 选择文件，两条数据自动合并
