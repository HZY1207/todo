# 待办清单

简约护眼待办事项应用，纯静态，无需构建工具。

## 功能

- 清单视图：添加 / 完成 / 编辑（双击文本，手机上长按）/ 删除待办，筛选（全部 / 进行中 / 已完成 / 未排期）
- 月历视图：每天格子上直接显示待办文字，点击日期查看并管理当日待办
- 未排期：添加时把日期留空即为「未排期」，月历顶部的「未排期 N」按钮集中管理这些待办；已有待办也能随时改日期或清空日期
- 三套护眼主题：绿白 / 黑白 / 蓝白（设置中切换，自动记忆，首帧前生效不闪烁）
- 删除有 6 秒撤销窗口，误删可恢复
- 数据保存在浏览器 localStorage（各设备独立）
- 数据互通：**导入并合并**（重复内容自动跳过）或**从备份还原**（先清空再恢复）
- PWA：手机浏览器可"添加到主屏幕"，安装后离线可用；有新版本时会提示刷新

## 本地运行

```bash
python -m http.server 8000
# 或任意静态服务器，浏览器打开 http://localhost:8000
```

直接双击 `index.html` 也能用（此时不会注册 Service Worker，也就没有离线能力）。
`http://localhost` 属于安全上下文，Service Worker 可以正常注册。

## 部署到 GitHub Pages（手机与电脑共用）

1. 创建 GitHub 仓库，将本目录推送上去
2. 仓库 Settings → Pages → Source 选择 `main` 分支 `/` 根目录，保存
3. 等待 1~2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

之后手机和电脑都打开同一链接使用。手机"添加到主屏幕"后即是独立 App 图标。

## 数据互通

1. 手机上 设置 → 导出数据 → 得到 `todo-backup-日期.json` 文件
2. 通过微信 / 网盘 / 邮件把该文件发给电脑
3. 电脑上打开同一网页 → 设置 → **导入并合并** → 选择文件

两种方式：

- **导入并合并**：把文件里的待办加进现有数据，内容、日期、创建时刻都相同的会自动跳过，不会翻倍。
- **从备份还原**：先清空当前数据，再完全按备份文件恢复。会先弹确认框，适合"换设备搬过去"。

## 操作提示

| 操作 | 桌面 | 触屏 |
| --- | --- | --- |
| 完成 / 取消完成 | 点击左侧圆圈 | 点击左侧圆圈 |
| 编辑内容与日期 | 双击文字，或点 ✎ | 长按文字，或点 ✎ |
| 删除 | 点 ✕（可撤销） | 点 ✕（可撤销） |
| 取消编辑 | Esc 或点 ✕ | 点 ✕ |

## 维护须知

改完 App 代码后，请把 `sw.js` 里的 `CACHE` 版本号一起加一（例如 `todo-v2` → `todo-v3`），
否则已经装过离线缓存的用户会一直拿到旧版本。
